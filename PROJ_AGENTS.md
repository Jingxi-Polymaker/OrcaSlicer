The goal of this initiative is to add OrcaSlicer Cloud support to OrcaSlicer.

We will support authentication and profile synchronization through OrcaCloud (Lane A for authentication and Lane B — Orca API Gateway — for data and synchronization services).

All the disign doc of the OrcaCloud is in the `spec` directory.
Always refer to the design doc when working on the code.
If you find any issues when working on commnunating with OrcaCloud from OrcaSlicer, please brainstorm with the users and ask user to update the design doc.
You should not make any changes to the design doc without the approval of the users.
